# Maintainers

Owner: RyansOpenSourceRice (first name only in shared artifacts: Ryan).

## Scope

This repo ships three OCI parser libraries for Ada (SPARK Silver): references,
image manifests, layer-apply planning. Building blocks for others to run
containers with — not a runtime.

## What this project does not do

- Content-addressable stores (`CAS.Index`) — parked, see ROADMAP.
- Linux capabilities — not considered for build or documentation, full stop.
- Container execution, filesystem extraction, registry I/O, networking.
- SDKs or meta-crates without an explicit consumer decision.

## Becoming a co-maintainer

Downstream-fork successor model: sustained, reviewed contributions over time;
ownership transfers by operator decision. AI-assisted contributions disclose
models used (see SECURITY.md).
